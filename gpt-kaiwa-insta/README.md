# GPT同士会話バズ動画システム 全体設計

## コンセプト
携帯2台でChatGPTの音声会話モードを起動し、それぞれに別キャラのマイGPTを仕込んで会話させる。
その様子を3台目（メイン機）で撮影し、リール/ TikTok / YouTubeショートに横展開する。

**バズの核**：「AI同士が勝手に喋ってる」という画の異常さ ×「キャラの掛け合い」の面白さ。
コメント欄で「次は○○モードやって」が湧く設計にして、ネタ切れをフォロワーに解決させる。

## 機材・アカウント構成
| 役割 | 機材 | 備考 |
|---|---|---|
| キャラA | スマホ1（ChatGPT音声モード） | マイGPT「Aキャラ」を起動 |
| キャラB | スマホ2（ChatGPT音声モード） | マイGPT「Bキャラ」を起動 |
| 撮影 | スマホ3 or 三脚固定 | 縦9:16・4K30fps・機内モード |
| 投稿 | Instagramプロアカウント | Graph API利用のためFacebookページ連携必須 |

- ChatGPT Plusが2アカウント必要（無料版は音声時間制限でNG。1アカウント2端末同時ログインは会話が混ざる事故があるので別アカ推奨）
- 静かな部屋・スマホ2台は30〜50cm離して向かい合わせ（近すぎると自分の声を拾ってループする）

## 投稿戦略
- **頻度**：週5〜7本（まとめ撮り1回で1週間分確保）
- **長さ**：30〜60秒。会話は撮って出しでなく「一番面白い往復」だけ切り出す
- **冒頭2秒**：テロップで状況説明「AI同士に○○させてみた」→離脱防止
- **ラスト**：「次に会話させたい2人をコメントで」→コメント誘発 → リーチ増
- **シリーズ化**：モード名を固定フォーマットに（例「AI大喧嘩シリーズ #3」）。当たったモードを擦り倒し、インサイトで週次判断

## リスク・注意
- ChatGPTの音声・挙動は仕様変更が入りやすい → 撮影前に1往復テスト必須
- 「AIっぽい定型文」が出たらそのテイクは捨てる（冷める最大要因）
- 音声モードはマイGPTの指示を無視しがち → prompts.mdの指示は「短く・命令形・禁止事項先頭」で設計済み
- 収益化やPR案件を見据えるなら、概要欄に「ChatGPTの音声機能を使用」と明記（ステマ・誤認防止）
