# 週次ルーティン＆チェックリスト

## 【初週】テスト撮り体制（課金は1アカウントだけ）
本格運用の前に、まず以下の構成で「画になるか」を検証する。

- スマホ1：ChatGPT **Plus**（マイGPTを作成するのもこのアカウント）
- スマホ2：**Gemini Live（無料）** または ChatGPT無料アカウント（音声無料枠は数分で切れるので短テイク用）
- 撮るもの：3テイクだけ
  1. モード8「VS Gemini」討論（ChatGPT vs Gemini どっちが優秀か）
  2. モード8 大喜利対決
  3. モード1〜7のどれか1本（ChatGPT無料枠の数分で試す）
- チェックポイント：キャラが何分もつか／会話がループしないか／スマホ同士の音の拾い合いが成立するか
- 判断：1本でも「これは伸びそう」があれば2アカウント目を課金して週7本体制へ。VS Geminiが強ければ2台目課金を遅らせてVS Geminiシリーズを主力にする選択もアリ

## 週の流れ（合計 実働2〜3時間で週7本）

| 曜日 | 作業 | 所要 | 自動/手動 |
|---|---|---|---|
| 月 朝 | GASがネタ7本＋キャプションをシートに自動生成 | 0分 | 自動 |
| 月〜金 | GASがリールを毎日自動投稿（19:00） | 0分 | 自動 |
| 土 | まとめ撮り（7〜10テイク） | 60〜90分 | 手動 |
| 土 | CapCutで一括編集 → Driveへ書き出し | 40〜60分 | 半自動 |
| 日 | シートに動画URL・投稿日をセット | 10分 | 手動 |
| 毎日 深夜 | GASがインサイトを自動記録 | 0分 | 自動 |

## 撮影セットアップ（初回だけ15分、以降5分）
- [ ] 静かな部屋。エアコン・換気扇の音に注意（音声モードが誤認識する）
- [ ] スマホA・Bを30〜50cm離して向かい合わせに置く（スタンド推奨）
- [ ] 両方のChatGPTアプリで該当マイGPTを開き、音声モード起動
- [ ] 撮影機は三脚固定・縦9:16・4K30fps・機内モード（通知混入防止）
- [ ] 画角：スマホ2台と画面が両方入る俯瞰 or 斜め45度
- [ ] 音声はスマホのスピーカー音をそのまま収録（ピンマイク不要。生活感がある方がバズる）

## 撮影の手順（1テイク）
1. 撮影開始 → 両GPTに「今からキャラ設定通りに会話して。説明は不要」と一言
2. topics.mdの「最初のひと言」をスマホAに向かって言う
3. 以後は放置。**2〜3分で必ずカット**（長いほど素のChatGPTに戻る）
4. 定型文・AI自認・長台詞が出たら即NGテイク → 撮り直し
5. 1ネタにつき使えたテイクが1本あれば次のネタへ

## 編集（CapCut・1本あたり5分目標）
- [ ] 初回に「マイテンプレ」を作る：冒頭テロップ枠＋字幕スタイル＋エンド画面
- [ ] 一番面白い往復だけ切り出して30〜60秒に
- [ ] 自動キャプション → 誤字だけ直す（キャラ名で色分け：A=白、B=黄など）
- [ ] 冒頭2秒テロップ「AI同士に◯◯させてみた」
- [ ] ラスト「次の組み合わせをコメントで👇」
- [ ] 書き出し：1080×1920 / 30fps → Google Driveの「投稿待ち」フォルダへ

## 投稿前の最終セット（日曜10分）
- [ ] Driveの動画を「リンクを知っている全員が閲覧可」にする
- [ ] スプレッドシート「投稿キュー」に行を追加：投稿日 / 動画のDriveリンク / キャプション（GAS生成分を微修正）
- [ ] ステータスを「予約」にする → あとはGASが毎日自動投稿

## NG集の扱い
- キャラ崩壊・変な誤認識は捨てずに保存 → 月1回「NG集」として投稿（稼働ゼロで1本作れる＋人間味でエンゲージが伸びる）

## 分析（月曜5分だけ見る）
- シート「インサイト」の再生数・保存数をモード別に見る
- 最も伸びたモードを翌週3本に増やし、最下位モードを新モードと入れ替える
- コメント欄の「◯◯やって」リクエストは新モードの最優先候補
